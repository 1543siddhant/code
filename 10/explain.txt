Theory

A distributed application is a program where data storage and processing are split across systems or nodes. In a weather-analysis problem, this usually means:

weather data is collected from an online source,
data is processed in parallel,
the result is computed using a distributed framework like MapReduce.
What is MapReduce?

MapReduce is a programming model used to process large datasets in parallel.

It has two main stages:

1) Map phase

Each input record is converted into intermediate key-value pairs.

For this problem, each weather record can be mapped as:

(year, temperature)
2) Reduce phase

All values with the same key are grouped together, and a summary is computed.

For this problem, the reducer calculates:

average temperature for each year

Then:

the hottest year is the year with the maximum average temperature
the coldest year is the year with the minimum average temperature
Basic flow
Weather Data -> Mapper -> (Year, Temp) pairs -> Reducer -> Avg temp per year -> Hottest/Coldest year

7) Mapper function
def mapper(df):
    result = []

    for _,row in df.iterrows():
        year = row['Year']
        tavg = row['tavg']
        result.append((year,tavg))

    return result
What it does

This is the Map phase.

For every row:

take the year
take the average temperature
emit a pair:
(year, tavg)
Example output
[('1990', 23.2), ('1990', 22.2), ('1991', 24.1)]
Meaning

This step converts raw data into key-value pairs grouped by year.

8) Run the mapper
mapped_output = mapper(df)
mapped_output
What it does

Calls the mapper and stores intermediate data.

9) Reducer function
def reducer(mapped_output):
    grouped = {}

    for year,tavg in mapped_output:
        if year in grouped:
            grouped[year].append(tavg)
        else:
            grouped[year] = [tavg]

    avg_by_year = {year: sum(tavgs)/len(tavgs) for year,tavgs in grouped.items()}

    return avg_by_year
What it does

This is the Reduce phase.

It:

groups all temperature values by year
calculates the average temperature for each year
Example

Input:

[
  ('1990', 23.2),
  ('1990', 22.2),
  ('1991', 25.0)
]

Output:

{
  '1990': 22.7,
  '1991': 25.0
}
10) Run the reducer
reducer_ouptput = reducer(mapped_output)
reducer_ouptput
What it does

Gets the average temperature for each year.

11) Find hottest year
hottest_year = max(reducer_ouptput,key=reducer_ouptput.get)
print("🔥 Hottest year:", hottest_year, "with avg temp =", reducer_ouptput[hottest_year])
What it does

That year is the coldest year.

Does this code satisfy the problem?
Partially yes

It satisfies the main goal of the assignment:

it reads weather data,
processes it,
computes yearly average temperatures,
finds the hottest and coldest year.
But not completely

It does not fully satisfy the “distributed application” requirement because:

It is not using a real distributed framework
No Hadoop MapReduce
No Spark
No multiple nodes
It does not fetch weather data from the Internet in the code
It loads a local file: mumbai_weather.csv
The MapReduce is only simulated
The mapper() and reducer() functions are plain Python functions
They are not running in a distributed cluster
So the correct judgment is:
Good for logic demonstration
Not a full distributed MapReduce implementation
Main issue in the notebook

The notebook is essentially a single-machine Python solution that imitates MapReduce.

If your teacher expects a true distributed assignment, you should mention:

“This notebook demonstrates the MapReduce idea using Python functions, but to make it
 fully distributed, it should be implemented using Hadoop Streaming, Hadoop MapReduce, or Apache Spark.”
